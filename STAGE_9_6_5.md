# Stage 9.6.5 — Plain-Language Tactical UX

Дата завершения: 2026-08-24. Версия приложения: `0.11.0`. Locale schema: `3.0.0`.
Tactical schema/rule остаются `1.0.0 / tactical_intelligence_v2.0.0`.

## Проблема

Первый вариант Tactical V2 одновременно показывал пользователю проценты, дроби, количество
матчей и раундов, coverage counts, T/CT, tick, UUID и специальные переходы. Точные данные были
правильными, но экран читался как диагностический инструмент разработчика.

## Новый путь чтения

1. Пользователь сразу видит, мала ли выборка.
2. Блок «Что важно заметить» показывает не более трёх сильнейших по размеру выборки типов.
3. Основной список показывает по одному представителю каждого раздела — не более десяти карточек
   без выбранных фильтров.
4. Карточка отвечает обычными словами: что произошло, как часто это встречалось и достаточно ли
   матчей для доверия.
5. Кнопка открывает конкретные раунды. На evidence card остаётся одно очевидное главное действие:
   2D-карта, ход раунда либо матч — в зависимости от реально доступного evidence.
6. Проценты, дроби, число доказательств, limitations, ticks, UUID и версии открываются только по
   явному запросу пользователя.

## Детерминированный словарь частоты

- `100%` — «в каждом подходящем случае»;
- `75–99.9%` — «почти всегда»;
- `50–74.9%` — «часто»;
- `25–49.9%` — «иногда»;
- `0.1–24.9%` — «редко»;
- `0%` — «пока не встречалось».

Эти слова описывают только сохранённую выборку. Один матч всегда сопровождается заметной подписью
«пока изучен только один матч». При сохранённом `small_sample_warning` вывод называется
предварительным. Никакая LLM и эвристика намерения игроков не используются.

## Что не изменилось

- numerator, denominator, sample size, frequency и evidence references;
- Tactical engine, schema/rule, fingerprints и source pins;
- DuckDB schema и immutable runs;
- JSON API;
- существующие рекомендации и отчёты.

Default curation полностью обратима: выбор конкретного типа показывает все его сохранённые
варианты. Поэтому удобство чтения не превращается в потерю доказательств.

## Acceptance

- RU/EN catalogs имеют одинаковые ключи и не смешивают языки;
- raw rotation arrows, heatmap coordinates и T/CT не используются как основной текст;
- точный ratio и percentage остаются в раскрываемом объяснении;
- evidence page сохраняет exact-run ссылки, но прячет специальные переходы во второй уровень;
- API payload до и после смены языка совпадает;
- presenter tests доказывают, что curation не меняет исходные insights;
- полный release gate и проверка на реальном FACEIT-профиле обязательны перед тегом.
