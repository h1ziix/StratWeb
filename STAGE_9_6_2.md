# Stage 9.6.2 — versioned locale contract

Дата завершения: 2026-08-24. Версия приложения: `0.10.2`. Версия locale schema: `2.0.0`.

## Результат

Общий shell и Tactical Intelligence V2 имеют полные русскую и английскую версии. Язык
переключается в шапке страницы, передаётся как `?lang=ru|en` и сохраняется в локальной cookie.
Переключение не запускает аналитику и не меняет ни один persisted объект.

## Контракт

- приоритет: валидный query `lang` → валидная cookie `stratweb_locale` → `ru`;
- неподдерживаемая локаль не сохраняется и не угадывается;
- каждый каталог содержит тот же набор ключей и те же именованные placeholders;
- отсутствующий ключ показывается буквально, чтобы ошибка была заметна разработчику;
- Jinja locale привязана к одному render call, а не к изменяемой глобальной переменной;
- canonical enums, insight keys, evidence, UUID, fingerprints и API payload не переводятся;
- переключатель показывается только на полностью локализованной поверхности.

## Изменения реализации

- `locale_catalogs.py` содержит стабильные `ru`/`en` каталоги;
- `i18n.py` отвечает за validation, resolution и presentation helpers;
- Tactical presenter возвращает message keys и typed interpolation values;
- шаблон Tactical V2 не содержит зашитого русского текста;
- внешний JS сохраняет существующие фильтры URL при смене языка и сбрасывает только страницу;
- cookie имеет `HttpOnly`, `SameSite=Lax` и срок один год.

## Acceptance

- русский URL рендерит `lang=ru` и русские product labels;
- `?lang=en` рендерит `lang=en`, английский shell, карточки, фильтры и ограничения;
- следующий запрос без query использует сохранённый английский;
- некорректный `lang` не записывается;
- locale switch до и после даёт одинаковый JSON tactical summary;
- locale catalogs имеют одинаковые ключи/placeholders;
- Pytest, Ruff, Mypy, package build и Docker Compose config проходят.

## Осознанные ограничения

Испанский и китайский не объявлены поддерживаемыми. Добавление частичного каталога создало бы
смешанный интерфейс, поэтому они остаются следующим расширением локализации. Остальные старые
страницы пока сохраняют русский presentation contract и не показывают переключатель.

Stage 9.6.3 (HTML evidence drill-down) этим этапом не начат.
