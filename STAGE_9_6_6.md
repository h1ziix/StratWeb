# Stage 9.6.6 — One-Tap UX & Visual Identity

Дата завершения: 2026-08-24. Версия приложения: `0.12.0`.
Design system: `2.0.0`. Locale schema: `3.1.0`.

## Зачем понадобился этап

Предыдущий интерфейс уже объяснял тактические данные обычными словами, но пользовательский путь
оставался похожим на панель аналитика. На странице одновременно находились фильтры, метрики,
экспорты, проверки, переходы и кнопки каждой карточки. На телефоне пользователю приходилось
сначала разбираться в интерфейсе, а потом уже читать разбор.

## Новый основной путь

Профиль соперника теперь предлагает одну главную кнопку — «Показать план на матч». Она открывает
простой режим из шести последовательных шагов:

1. достаточность выборки;
2. повторения соперника за атаку;
3. повторения соперника за защиту;
4. доказанные сигналы риска и индивидуальные привычки;
5. только прошедшие readiness gate контрстратегии;
6. ссылки на реальные раунды и ограничения.

На телефоне шаги переключаются кнопкой «Дальше» или горизонтальным свайпом. Старый полный отчёт
доступен через меню `•••` как режим аналитика. Он не удалён и по-прежнему содержит фильтры,
точные числа, provenance и экспорты.

## Детерминированная курация

Coach projection читает тот же закреплённый `ScoutingReportSource`. Для каждого раздела он:

- сортирует findings по признаку малой выборки, числу матчей evidence, sample size и frequency;
- оставляет один finding каждого pattern type;
- показывает максимум три сигнала;
- сохраняет исходный `finding_id` и detail/evidence link.

Курация не пересчитывает numerator, denominator, confidence или readiness. Если risk finding или
принятая рекомендация отсутствует, UI показывает пустое состояние и не генерирует совет.

## Визуальная система

Design system `2.0.0` заменяет orange/blue identity на graphite/mint. Основной цвет используется
для направления внимания; amber и red остаются только предупреждениями, а цвета игровых сторон
не переопределяют продуктовую палитру. Добавлены мягкая глубина, progress motion и entrance
transition. `prefers-reduced-motion` отключает движение.

## Acceptance

- default report route открывает coach mode, `mode=analyst` — полный прежний отчёт;
- до запуска видна одна основная action;
- каждый coach section содержит не более трёх signals;
- active step отражается URL fragment и не записывается в базу;
- touch, focus, reduced-motion и no-JS paths определены;
- JSON report API и immutable analytical contracts не изменены;
- реальный профиль с одним FACEIT-матчем честно показывает preliminary state и отсутствие готовых
  рекомендаций;
- Stage 9.7 не начат.
